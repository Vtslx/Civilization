## Translation policy

- The English README is authoritative. If a translation and the English text
  disagree, the English text is correct.
- Technical identifiers (`provider`, `local_transformers`, `local_adapter`,
  `CIVILIZATION_MODEL_PATH`, stage numbers, version codenames, file paths) are
  kept verbatim in every language so that commands and configuration stay
  copy-pasteable.
- Translations of the claims boundary are literal on purpose. Every language
  states the same limits: no new foundation model, no lifelong-learning claim,
  no biological equivalence, and no hidden-state claim for text-only runtimes.
- Corrections and additional languages are welcome as pull requests; add the
  file here and list it in the table above.
