## 新增能力

- **类型化上下文包。** 检索到的记忆被打包为类型化上下文包，而不是无结构列表（`stage139_rosette_context_packet`）。
- **原子冲突预算。** 预算限制一个包可携带多少相互矛盾的材料，使单个冲突无法吃掉整个上下文（`stage140_rosette_atomic_budget`）。
- **校验与快照。** 包校验器、包快照与快照恢复（`stage141`–`stage143`）。
- **蜂窝图谱。** 记忆单元上的多尺度图，含遍历、结构校验、快照与恢复（`stage145`–`stage149`）。
- **发布门。** 两个可复现的门：包合同一个、图合同一个（`stage144`、`stage150`）。

## 基线合同

- 违反类型合同的包会被拒绝，而不是被部分使用。
- 冲突预算被强制执行：超预算时校验失败，而不是静默丢弃证据。
- 快照恢复出与校验通过时完全一致的结构；恢复不会伪造节点或边。
- 两个发布门均可复现，并写出可审计摘要。
